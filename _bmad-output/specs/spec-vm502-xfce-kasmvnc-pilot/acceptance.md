# 验收要求

以下均为待执行的验收契约；本次规格整理不产生任何运行通过结论。每项在实际交付版本上记录结果、目标、操作与脱敏证据。

## 证据层次与前置条件

- **L（离线）**：配置、协议及状态逻辑使用合成 fixture 验证；不加载生产秘密、不连接生产目标、不触发外部写入流水线。
- **R（隔离运行）**：在同 OS/架构、无员工数据或个人凭据的已授权环境验证真实安装、systemd/X11、进程归属、并发与中断。依赖安装仍须有授权；仅依赖解析不能记为运行通过。
- **N（实网/维护）**：明确精确目标；只读盘点按既有只读权限执行，涉及撤销、切换、重启、轮换等外部写入时须有相应授权。破坏性反例先用 fixture；不擅自停用真实员工。
- **U（本人 UAT）**：本人操作真实订阅授权、中国侧设备和代表性任务。匿名输入检查、截图、服务启动或澳洲本地结果不能替代。

每项证据至少包含 AC-ID、交付文件版本/摘要、实际目标与环境、相关设备/浏览器、动作、预期与实际结果、时间和脱敏附件引用。结果使用“通过”“失败”“未执行（原因）”；前置未满足记为未执行，不折算通过。输出不含 OAuth URL、令牌、密码、私钥或 profile 内容；截图不得暴露个人账号、验证码与页面会话。

## 完成判定

实施完成需相关离线/隔离运行验证通过并交付对应版本和授权后执行的验收说明；上线验收还需全部适用 N/U 项通过。若安装兼容失败、任一隔离/撤销失败、共享入口迁移导致 legacy 不可用，或本人 UAT 未完成，记录实际状态并停在对应边界，不宣布试点整体成功。

本矩阵只验证 VM502 试点及共享入口迁移；历史整体员工工作区验收和其他员工桌面推广不由它替代。
