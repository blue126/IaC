# Research Brief

- Topic: OpenCode remote worktree support
- Decision: Determine whether remote OpenCode Server worktree workflows are natively supported, require a plugin, or should be deferred.
- Type: Technical research
- Preset: Quick
- Validation: Normal
- Scope: Official documentation, source, releases, and issue tracker. Community plugin source auditing is excluded.

## Questions

1. Is the Beta workspace UI restricted to a local Desktop-managed server?
2. Does OpenCode Server expose native worktree APIs usable by remote clients?
3. Can a plugin add the missing Desktop UI, or only expose agent-side tools?
4. What is the lowest-risk option for a remote devcontainer server today?
