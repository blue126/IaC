部署流水线 Jenkinsfile · IaC-Homelab-Pipeline

1
PR 校验

GitHub Actions 按改动分类：fmt / validate、ansible-lint、syntax-check、文档构建

2
合并 main → webhook

经 Cloudflare Tunnel 进 CT107，webhook-router 分发

3
Check Changes · Setup · Validate

按 diff 选目录；get-secrets.sh 生成 tfvars

4
Terraform Plan

保存 tfplan，-detailed-exitcode 判断有无变更

5
人工批准 → Apply

审阅 plan 后执行，随后 Refresh Inventory

6
人工批准 → Ansible Deploy

只跑受影响的 playbook，最后同步到 Notion

另一条线RemoteCC 不走 Jenkins：Semaphore 在 remotecc-ops 上调用 wsctl。
