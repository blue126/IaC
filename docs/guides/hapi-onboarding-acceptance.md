# HAPI 新员工开户真实验收清单

状态：准备清单，尚未执行。本清单不授权安装SDK、创建VM、写入BWS／Cloudflare、发布控制面或发送邮件。应用候选代码及已有隔离证据见[应用开户说明](hapi-application-onboarding.md)。

## 进入验收前

- 定向复核最后四项P2修正，记录结论及仍需现场验证的接口。
- 公开IaC／skill和私有管理员源码分别提交，记录两个commit及部署源码摘要；side chat的现有工作区挂接改动独立保留。
- 私有源码仍使用任务开发副本；切换正式管理员入口前明确源码、数据、Sandbox绑定和失败回退，不自动覆盖正式入口。
- 保持SDK暂缓安装。恢复验证前单独取得安装授权；随后先验证官方SDK的实际签名、类型与读接口，再批准指定测试材料的写入及回读。
- 核对VM500已部署共享防火墙控制器的精确版本。若不支持HAPI扩展，先准备由原角色或独立迁移计划发布的变更，HAPI开户本身仅校验摘要。
- 单独审阅VM500身份确认能力的升级计划；现网未升级时，应用计划必须明确拒绝，不能跳过版本门禁。

## 受控测试资源

使用PVE真实网络配置及两台从干净模板创建的员工测试VM。通过HAPI独立Terraform state分配VMID、IP、MAC；不复用已退役的QA输入，不把VM500／VM502作为新员工目标。正式申请与计划需写明模板、节点、分配范围、磁盘、网络、保留期限和销毁归属，再审批执行。费用涉及付费资源时先列出单价和上限；本清单不预设购买或创建。

两种测试身份在私有登记中分别绑定，公开文档使用“员工A／员工B”。不发送通知；先生成私有交付材料，由测试人员自行完成Cloudflare验证及个人Claude授权。

## 分阶段执行与证据

| 阶段 | 验收内容 | 成功证据 |
|---|---|---|
| SDK／BWS | 类型和固定版本可用；仅指定项目可访问；创建、回读及重试不重复生成；确认后的登记被删除不能恢复 | 私有操作回执，不含秘密值 |
| Hub凭据 | 用合成凭据验证新增可热加载、namespace固定、停用撤销已有连接；不只验证旧凭据删除 | 固定Hub版本、隔离回归记录 |
| 基础设施 | 独立state、VM UUID／IP／MAC、可信SSH主机密钥、首次启动门禁；sudo后仍不能跨VM／管理网段 | 精确Terraform plan、资源与网络回读 |
| VM500前提 | 身份确认接口版本正确；防火墙控制器摘要一致；静态角色拒绝覆盖应用登记 | 升级及校验回执 |
| 私有服务 | worker只运行Runner和登录执行组件；mTLS的证书、CRL、来源IP正确；实际Runner对应本人VM | 安装与实际请求回读 |
| 防火墙 | 真实内核规则格式、位置及入口网卡符合预期；基础reload重放扩展；扩展失败不关闭基础转发 | 受控两VM实测及基线前后对照 |
| Access | 专用策略创建、排序、模板安全约束及回读正确；模板原有放行范围单独核实；已撤销策略不恢复 | 指定app下的脱敏策略回执 |
| 身份确认 | A／B各自登录；GET不绑定，POST才确认；错邮箱、重复subject、过期票据拒绝；确认后重新计划保留身份 | 浏览器结果和脱敏登记回读 |
| 应用入口 | 各自只见本人任务；HTTP、SSE、Socket.IO、RPC及RFB跨人访问拒绝；不再输入HAPI token | 两人分别操作的公网路径记录 |
| 个人Claude | 保留有效授权；未登录员工自行完成首次引导；已有VM502不登出、不清理个人目录 | 本人操作与状态回读 |
| 失败重试 | 应用启用回执丢失后阻断本人入口，再按原计划核查；旧计划不能覆盖新计划；其他员工不中断 | 失败注入及恢复记录 |

`route_enabled`仅代表私有服务及VM500登记通过。公网网页／实时／登录画面完成验证后才能设计并批准`public_entry_ready`的正式置位实现；当前候选执行器始终保持该字段为false。个人Claude授权、员工验收和通知状态分别记录。

## 停止与回收

任一身份、资源归属或代码摘要不符即停止；失败只阻断本人入口，保留其他工作区。全量停用／恢复／退役执行器仍未交付，试点前必须准备逐资源的回退和回收计划，不把未实现命令写进交付步骤。

测试结束后，按原Terraform state生成精确销毁计划，审阅并执行；BWS测试材料、Access专用策略、VM500测试登记与防火墙例外也须按精确ID单独清理。保留不含秘密的验收记录。长期启用之前，补齐新worker证书／CRL监控、续期与恢复安排。
